# Image assets

Store the site's image files in this directory.

## Suggested files

- `products/product-image.webp` — product image used on the shop/product cards.
- `products/home-product-image.webp` — product image featured on the homepage.
- `branding/site-logo.svg` — primary site logo.
- `branding/site-logo-white.svg` — white logo variant, if needed.

Use SVG for logos and other clean vector artwork; use optimized WebP (or PNG where transparency is required) for product photography. Update the relevant HTML/CSS image paths when adding the actual files.
